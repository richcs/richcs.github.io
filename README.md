# richcs.github.io

Personal portfolio website for Richard Lei, live at **[richcs.github.io](https://richcs.github.io)**.

## Stack

Pure HTML, CSS, and vanilla JS — no build step, no dependencies.

## Deployment

Push to `main`. GitHub Pages deploys automatically.

## Structure

| File | Purpose |
|------|---------|
| `index.html` | All page content and sections |
| `style.css` | Dark theme, CSS variables, responsive layout |
| `main.js` | Navbar scroll effect, fade-in animations |
